# Security policy

Use [GitHub’s private form](https://github.com/silasthegoldenwizard/ja2-1.13-native-linux-riscv64/security/advisories/new) to report a security vulnerability in this port.

Include the affected release or commit, the steps to reproduce the problem, and its impact. Keep original JA2 game data, saves, profiles, and credentials out of the report.

Use the [gameplay bug form](https://github.com/silasthegoldenwizard/ja2-1.13-native-linux-riscv64/issues/new?template=gameplay-bug.yml) for ordinary crashes and other gameplay bugs.
